Linear map — A·v = [a b; c d]·[x; y] = (a·x + b·y, c·x + d·y)
Columns are images of the basis — A·e₁ = (a, c)ᵀ (column 1) and A·e₂ = (b, d)ᵀ (column 2); since v = x·e₁ + y·e₂, then Av = x·Ae₁ + y·Ae₂.
Area & orientation — det A = a·d − b·c: |det| is how areas scale (shaded unit square), the sign flips with orientation (improper maps, det < 0).
Self-contained single file · no external dependencies · white/monochrome. Slide-ready: <iframe src="widget.html"> or inline the mm-root block into a reveal slide; scriptable via window.mm2 (e.g. mm2.setA(0,-1,1,0)).
